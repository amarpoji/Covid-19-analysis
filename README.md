# 🦠 COVID-19 EDA Project

This project explores global COVID-19 statistics from a public dataset using Pandas, NumPy, Matplotlib, and Seaborn.

## 📁 Dataset
- Source: Kaggle
- Columns analyzed: Confirmed cases, Deaths, Recovery rates, Weekly changes

## 📊 Key Analyses
- Top 10 countries by total confirmed cases
- Countries with the highest death rate
- 1-week percentage increase in new cases
- Scatter plot: Recovery vs Death rate, by WHO region

## 📌 Tools Used
- Python
- Pandas & NumPy
- Seaborn & Matplotlib
- Jupyter Notebook

## 📷 Visualizations
All charts are available in the notebook — bar plots, scatter plots, and heatmaps.
